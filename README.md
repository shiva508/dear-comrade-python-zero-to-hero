# Objects Data Structure

| Name           | Type | Description                                           |
|----------------|------|-------------------------------------------------------|
| Integer        | int  | numbers such as 1,2,3 so on                           |
| Floating Point | flot | numbers with decimal point 1.2, 3.16                  |
| Strings        | str  | Group of characters                                   |
| List           | list | Group of objects ["Shiva",2,4.12]                     |
| Dictionaries   | dict | un-ordered key-value pair {"name":"Shiva","age":34}   |
| Tuples         | tup  | ordered, un-changeable group of objects (1,"hello",3) |
| Sets           | set  | un-ordered, un-indexed group of unique objects {1,2,3}|
| Boolean        | bool | True or False values                                  |
